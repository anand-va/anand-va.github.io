Hi, I'm Anand, a security engineer at Deep Armor in Bengaluru. I find the cracks in code for a living, politely and with permission, so they get fixed before someone with worse intentions finds them. Part of that is teaching scanners what trouble looks like: I write Semgrep rules that sniff out the classics from the OWASP Top 10, like SQL injection and cross-site scripting. Scanners are noisy, though, so the fun part is digging into what they flag and proving which bugs are real and which are false alarms. I've taught an AI agent to do the first round of that digging, turning a day or two of work into minutes, but I still get the final say. Before all this, I built the checks in Gauntlet that catch AWS and Azure accounts left with the doors unlocked. Got something that needs breaking, or just want to talk shop?
